One-time setup

Connect your YouTube API key

Luma streams public video data from the official YouTube Data API v3. Add a free API key once and you're good to go — it stays on this device.

  1. 1
    Open Google Cloud ConsoleCreate a project (or pick an existing one).
  2. 2
    Enable “YouTube Data API v3”APIs & Services → Library → search for YouTube Data API v3.
  3. 3
    Create an API keyAPIs & Services → Credentials → Create credentials → API key.
  4. 4
    Paste it belowOr hard-code it in script.js.
const YOUTUBE_API_KEY = "YOUR_API_KEY_HERE";
